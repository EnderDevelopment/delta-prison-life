# Delta Prison Life Game

This is a Roblox game where players experience prison life. The game includes a prison environment and basic player mechanics. The prison is created with walls, a floor, and a roof, and players are given a simple character model with a humanoid. The game also includes a basic economy system where players start with an initial amount of money.

## Install

1. Place the `DeltaPrisonLife.server.lua` script in the `ServerScriptService` folder in Roblox Studio.
2. Run the game in Roblox Studio to see the prison environment and player mechanics in action.

## Use

1. Open Roblox Studio.
2. Create a new Roblox game or open an existing one.
3. Place the `DeltaPrisonLife.server.lua` script in the `ServerScriptService` folder.
4. Run the game to start the Delta Prison Life game.
